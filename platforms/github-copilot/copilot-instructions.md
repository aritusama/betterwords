# GitHub Copilot instructions

When generating, editing, reviewing, or summarizing durable prose in this repository, apply the betterwords rules from `docs/betterwords.md`.

Durable prose includes README text, docs, release notes, issue text, pull request descriptions, specs, product copy, newsletters, scripts, and slide text.

Do not apply betterwords to ordinary chat or code comments unless the user asks.

If `docs/betterwords.md` is missing or inaccessible, say that the betterwords rule file is missing instead of guessing the rules.

Preserve supplied facts, attribution, uncertainty, scope, and required format. Do not add facts, sources, quotes, numbers, examples, product claims, or firsthand experience.
