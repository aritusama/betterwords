# GitHub Copilot setup

Use this for GitHub Copilot Chat, code review, or agent work in a repository.

## Repository setup

1. Copy `betterwords.md` into the target repository. A clear path is `docs/betterwords.md`.
2. Copy `platforms/github-copilot/copilot-instructions.md` into the target repository as `.github/copilot-instructions.md`.
3. If you put `betterwords.md` somewhere other than `docs/betterwords.md`, update the path inside `.github/copilot-instructions.md`.
4. Use Copilot for docs, README, release notes, specs, issue text, PR descriptions, and other durable writing in that repository.

## Personal setup

For GitHub.com Copilot Chat, you can also add the short betterwords behavior rules from `platforms/common-instructions.md` as personal instructions. Keep `betterwords.md` available in the repository or paste it into the chat when needed.
