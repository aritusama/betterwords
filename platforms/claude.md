# Claude setup

Use this for Claude outside Codex.

## Best setup: Claude Project

1. Create a Claude Project.
2. Upload `betterwords.md` to the project knowledge base.
3. Put the contents of `platforms/common-instructions.md` in project instructions.
4. Start chats inside that project when you want betterwords to apply.

## One-off setup

Attach or paste `betterwords.md`, then paste the contents of `platforms/common-instructions.md`, then provide the draft or writing task.
